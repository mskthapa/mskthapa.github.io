# Nepal Weather ⛅🇳🇵

A **real-time weather dashboard** for cities across Nepal, built with [Astro](https://astro.build) - the modern static site builder.

## ✨ Features

- 🌤️ Live weather data for major Nepali cities
- 🔍 Search any city in Nepal
- 🌡️ Temperature, humidity, wind speed & conditions
- 📱 Fully responsive design (mobile & desktop)
- ⚡ Fast static site performance with Astro

## 🏙️ Supported Cities

- Kathmandu
- Pokhara
- Biratnagar
- Lalitpur
- Bhaktapur
- Chitwan
- *And more!*

## 🛠️ Tech Stack

- [Astro](https://astro.build) - Core framework
- HTML5, CSS3, JavaScript
- [OpenWeatherMap API](https://openweathermap.org/api) - Weather data
- Deployable to Netlify, Vercel, or GitHub Pages

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/mskthapa/nepal-weather.git

# Navigate to project
cd nepal-weather

# Install dependencies
npm install

# Start development server
npm run dev
